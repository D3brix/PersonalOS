# Instructions for AI assistants

This folder is a PersonalOS vault: the owner's personal knowledge base in plain Markdown.

## Before acting
1. Read `99_System/Rules.md`, and the other `99_System/` files that matter for the task. They are authoritative.
2. Use `Current_Focus.md` to understand current priorities.
3. Search with `personalos search <keywords>` instead of reading whole folders.

## Trust levels
- `99_System/`: authoritative. Never edit it; write proposals in `99_System/Proposed_Changes.md`.
- `04_Knowledge/`, `02_Projects/`, `03_Areas/`: curated notes. Check their dates.
- `00_Inbox/`, `raw/`: unprocessed. Never treat these as facts.
- AI-written memory and past conversations are context, not facts. Confirm them against a note.

## Boundaries
- Prefer updating an existing note over creating a duplicate. Never delete notes; move them to `09_Archive/`.
- Never put passwords, keys or tokens in notes.
- Ask before sending messages, publishing, spending money or making commitments on the owner's behalf.
- Never claim something was done unless you verified it.
