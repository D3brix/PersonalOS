# System layer

The authoritative description of you and the rules your AI assistants follow. Assistants read these files before
acting and never edit them directly: they write proposals in [[Proposed_Changes]], you approve, and the change
is recorded in [[Changelog]].

- [[Identity]]: who you are
- [[Goals]]: what you are working towards
- [[Preferences]]: how you like to work and be communicated with
- [[Rules]]: binding rules for assistants
