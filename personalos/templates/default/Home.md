# Home

Start here. This vault is your PersonalOS: plain Markdown files that you own, organized so that both you and
an AI assistant can find what matters.

## Now
- [[Current_Focus]]: what you are working on this week
- Projects: `02_Projects/` (run `personalos projects`)
- Goals: [[Goals]]

## How the vault is organized

| Folder | Holds | Example |
|---|---|---|
| `00_Inbox/` | Quick captures, not yet sorted | "Look into standing desks" |
| `01_Daily/` | Daily notes | `2026-01-15.md` |
| `02_Projects/` | Efforts with a finish line | "Move to a new flat" |
| `03_Areas/` | Ongoing responsibilities | Health, Finances |
| `04_Knowledge/` | Processed, trustworthy knowledge | "How index funds work" |
| `05_People/` | Notes about people | A mentor, a client |
| `06_Skills/` | How an AI (or you) performs something repeatable | [[Knowledge_Processing]] |
| `07_Systems/` | Recurring workflows | [[Inbox_Workflow]], [[Weekly_Review]] |
| `08_Resources/` | Reference material | Manuals, links, clippings you trust |
| `09_Archive/` | Finished or inactive material | Completed projects |
| `raw/` | Unprocessed material | Exports, transcripts, dumps |
| `99_System/` | Your identity, goals, preferences and rules | [[Rules]] |

`99_System/` is the authoritative layer: an AI assistant should read it before acting on your behalf, and should
propose changes to it in [[Proposed_Changes]] rather than editing it.

## Everyday commands
- `personalos capture "an idea"`: save something to the inbox
- `personalos search <words>`: find anything, most trustworthy sources first
- `personalos ui`: open the local interface
- `personalos maintain`: weekly tidy-up suggestions (it never changes your notes)
