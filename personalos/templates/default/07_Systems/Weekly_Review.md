# Weekly review

A 20-minute routine that keeps the vault trustworthy.

1. Run `personalos maintain` and read the report. It only suggests; you decide.
2. Empty the inbox with [[Inbox_Workflow]].
3. Update [[Current_Focus]].
4. For each active project: is the status still true? Move finished projects to `09_Archive/`.
5. Add anything you decided to the [[Decision_Log]] and anything you learned to [[Lessons_Learned]].
6. Once a month: `personalos backup --to <folder outside the vault>`.
