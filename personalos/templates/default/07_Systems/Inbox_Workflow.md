# Inbox workflow

How items in `00_Inbox/` are processed. Run it whenever the inbox has more than a handful of items, and at
least during the [[Weekly_Review]].

## For each item
1. Read it. Process items one at a time; never batch-sort without reading.
2. Decide what it actually is, then move it:
   - known, trustworthy information -> `04_Knowledge/` (via [[Knowledge_Processing]])
   - an effort with a finish line -> `02_Projects/`
   - an ongoing responsibility -> `03_Areas/`
   - about a person -> `05_People/`
   - a reusable method -> `06_Skills/`; a recurring workflow -> `07_Systems/`
   - reference material -> `08_Resources/`
   - not processable yet -> `raw/`, or leave it with a note saying what is missing
3. Goals and direction changes are never filed directly into `99_System/`. Draft a proposal in
   [[Proposed_Changes]] instead.
4. Delete nothing. Something with no value goes to `09_Archive/`.

## Assistants
An assistant may sort the inbox when asked, following this note. It must say what it moved where, and it must
leave anything ambiguous in place with a question.
