# Projects

A project is a temporary effort with a defined outcome. One note per project. Start each note with:

```
---
status: active        # active | waiting | done | dropped
outcome: what "finished" looks like
---
```

`personalos projects` groups projects by status. When a project is done, set `status: done` and move it to
`09_Archive/`; `personalos maintain` reminds you.
